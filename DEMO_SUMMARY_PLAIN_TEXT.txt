1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
This progress report documents the Phase-1 accomplishments of our 4-member capstone team — B. Sai Tejaswi, Sharanya, Priya, and Harshini — for the project "SENTINEL-AI: AI-Powered Website Trust & Fraud Detection System".

In Phase 1, our team successfully built the foundational system architecture, normalized 3NF MySQL relational database, Spring Boot REST API framework, Python Flask AI prediction microservice, and React single-page user interface.

A working end-to-end prototype has been verified: financial transactions submitted through the React frontend are validated by Spring Boot, evaluated by the Python Flask AI service to assign a fraud probability and a normalized risk score (0–100), persisted into MySQL, and displayed live on the admin dashboard.
