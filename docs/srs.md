# Software Requirements Specification

## 1. Introduction
This project develops an AI-powered fraud detection system that monitors financial transactions, predicts fraud risk, and alerts administrators.

## 2. Functional Requirements
- User registration and login
- Transaction creation and history
- Fraud prediction and risk score generation
- Admin monitoring dashboard
- Alert generation for suspicious transactions

## 3. Non-Functional Requirements
- Secure password storage
- RESTful API design
- Responsive UI
- Modular and documented code
